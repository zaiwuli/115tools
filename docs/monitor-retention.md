# 云监测原包处理

来源管理编辑普通115来源：使用处理规则中的原包处理方式。新来源默认关闭；旧来源缺省保持原行为。关闭时新登记任务强制保留原包，不影响解压和提层等规则；离线来源不受影响。

处理规则提供保留、移动、归档、删除（逐任务批准）。移动和归档均移动云端原文件，目标 CID 留空使用系统归档目录。归档可按任务首次登记日期创建子目录；移动不创建日期子目录。日期记录在任务策略中，跨天重试不变。删除仍须成功后人工批准并遵守延迟删除。

生活事件监测排除系统输出目录和启用规则中的自定义归档/移动目标及其子目录，避免归档重新触发监测。不新增递归扫描。修改配置只影响新任务，旧任务使用已保存的策略（现有后处理仍会检查规则版本，修改规则后旧任务可能要求人工处理）。

归档失败单独重试后处理，不重新解压。远端移动结果未知时保留原有核对保护，不盲目重发。失败原包归档未增加日期选项。
