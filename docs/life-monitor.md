# 生活事件增量发现

首次无成功检查点时只请求当天最新一页（1000条），不按开启时间排除该页旧记录，不向前回查。已有部署沿用检查点。

后续从当天向前读取至旧事件ID边界或上次检查日期；同一轮最多10页，页间3秒，页面重叠100条并按事件ID去重。偏移分页不能提供强一致快照；同时大量插入、删除时不能绝对保证无遗漏。

先本地合并同文件最新事件，跳过浏览/删除及明确非压缩包文件名，再校验候选父目录路径。同父目录本轮只查一次，匹配启用来源根目录或其子目录后只扫描变化目录当前层，不递归。没有文件名的记录保守查目录；不支持只移动整个文件夹而没有内部文件事件的完整发现。

必要事件缓存在Settings的life-monitor-pending，完成可靠扫描任务登记后推进life-monitor-state并清理。每轮目录校验最多70个，保留100次任务请求预算；页数或目录批次达到上限显示LIFE_BACKLOG并保存进度，下一周期继续。认证/限流等异常不改变旧成功边界。若扫描任务已有预算耗尽标记，仍需手动恢复，不能据检查完成认定已解压成功。

新增监测来源使用之后事件；已完成检查点之前的历史事件不会自动重放。默认正常周期30分钟，手动检查可立即启动一轮。
