# Bark 触发云端变化检查

在支持自定义 Bark 服务器的工具中填写：

- 服务器地址：`http://NAS地址:9056/bark`
- 设备 key：连接管理中创建的操作令牌（只读令牌不可用）

支持 `POST /bark/push`，JSON 包含 `device_key`；也支持 `GET/POST /bark/{device_key}/{标题}/{正文}`。只验证令牌并接收触发信号，展示字段仅保存通知标题、正文及分组，不读取其内容来决定触发。成功返回 Bark 格式 `code: 200`。

须开启云端变化监测。第一条信号开启90秒固定窗口，窗口内通知合并，不延长窗口。结束后登记或合并一次云端变化检查，遵守原有查询预算和离线列表第一页限制。排队和全局暂停可能延迟实际执行。窗口保存在数据库，重启后可恢复。日志记录窗口开启和合并数量，不向控制台日志输出令牌或通知内容。

若工具硬编码官方 Bark 地址或不支持自定义服务器，此配置方式不可用。设备 key 位于 URL 的客户端应避免把完整推送 URL 发给他人；应用自身错误访问日志会遮蔽该路径。

## 查看收到的消息

连接管理提供基于当前访问地址生成的 Bark 服务地址和复制按钮。工作日志新增“运行日志”和“Bark 消息”分页；刷新后可查看接收信号、窗口调度与监测结果，以及收到的通知标题、正文和分组。

通知展示仅操作权限可见，最近保留50条，每字段最多4096字符。设备key和Bearer内容会遮蔽，不保存完整请求或任意附加字段。该功能上线前的通知正文未保存，无法补回。当前不根据正文筛选触发，仍沿用90秒合并窗口。
