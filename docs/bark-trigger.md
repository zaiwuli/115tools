# Bark 触发云端变化检查

在支持自定义 Bark 服务器的工具中填写：

- 服务器地址：`http://NAS地址:9056/bark`
- 设备 key：连接管理中创建的操作令牌（只读令牌不可用）

支持 `POST /bark/push`，JSON 包含 `device_key`；也支持 `GET/POST /bark/{device_key}/{标题}/{正文}`。只验证令牌并接收触发信号，不解析、不保存通知标题和正文。成功返回 Bark 格式 `code: 200`。

须开启云端变化监测。第一条信号开启90秒固定窗口，窗口内通知合并，不延长窗口。结束后登记或合并一次云端变化检查，遵守原有查询预算和离线列表第一页限制。排队和全局暂停可能延迟实际执行。窗口保存在数据库，重启后可恢复。日志记录窗口开启和合并数量，不记录令牌或通知内容。

若工具硬编码官方 Bark 地址或不支持自定义服务器，此配置方式不可用。设备 key 位于 URL 的客户端应避免把完整推送 URL 发给他人；应用自身错误访问日志会遮蔽该路径。
